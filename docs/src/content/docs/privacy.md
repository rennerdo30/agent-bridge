---
title: Privacy
description: What this website and agent-bridge itself collect.
---

**This website** is a static site hosted on GitHub Pages. It sets no cookies, runs no analytics and loads nothing from other servers. GitHub, as the host, logs visitor IP addresses for security; see the [GitHub privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).

**agent-bridge** runs on your own computers. It has no account, sends no telemetry and talks to no server of ours. Messages, jobs and history stay in SQLite under `~/.agent-bridge` on your machine. Data leaves a PC only when you pair it with another of your PCs, and then only over TLS to that PC. Usage checks ask each CLI's own provider, using that CLI's existing login. The coding CLIs it connects keep their own privacy terms with their providers.
