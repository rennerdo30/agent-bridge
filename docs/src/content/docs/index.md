title: "agent-bridge"
---

Connect Claude Code, OpenAI Codex, opencode and Google Antigravity CLI on one machine and on explicitly paired PCs. Agents exchange messages, delegate tasks, share project jobs and retain searchable history. Follow their work and answer questions in one local dashboard.

- [Install](getting-started/install/) and [update](getting-started/update/) the plugins.
- Follow the [first steps](getting-started/first-steps/).
- Learn about [sessions and project groups](concepts/sessions/) and [delegation](concepts/delegation/).
- Open the [dashboard](dashboard/) and answer [owner questions](concepts/owner-questions/).
- Browse the [MCP tools](reference/tools/), [CLI](reference/cli/) and [security](reference/security/) references.

Subagents are read-only by default. Set access deliberately and isolate editing jobs in worktrees. Messages from peers remain identified as peer messages.
